# 实机验收记录

记录项目环境与已完成检查，避免把规则测试当成视觉模型的准确率证明。

## 已验证的基础环境

- Windows 11 x64，独立 `Integrated IR Camera`，Realtek USB 摄像头驱动。
- Windows 枚举结果同时存在 IR-only source group；应用没有初始化彩色源。
- 红外链路实测：640×360、L8；12 秒处理 60 帧，约 4.9 fps，观察到一张人脸。
- 上述诊断的保护动作被强制禁用；不保存摄像头画面。
- 2026-10-07 首版 0.1.0：17/17 规则测试通过，包含断流、计时、优先级、校准偏移与连续有效帧门控。
- 最终发布目录的 Ui／Hardware 验证脚本均通过；浅深主题的四个页面、底部内容与紧凑布局已渲染并检查。
- 最终发布版红外复测：12 秒处理 59 帧，约 4.9 fps，观察到一张人脸；工作集约 221 MB。此结果只证明本机基础链路可用，不证明所有使用场景的准确率。

运行命令与报告由 README 的验证章节说明。实际 Windows DPI、键盘交互、视觉准确率与系统动作按下面清单人工验收。

## 0.1.1 修改验证（2026-10-07）

- 38/38 规则、位置跟踪与恢复协调器测试通过，包括左右映射、两侧／居中、主用户短暂丢失、靠近相机的旁观者、方向防抖、重试耗尽、手动暂停取消恢复、旧画面／错误回调、睡眠与锁屏交叠。
- Release 编译无警告、无错误；保留原依赖锁定版本。
- 新提醒卡片的浅深主题和 100%／150%／200% 渲染已检查。左、右、双侧和通用提醒通过前台窗口不变检查与鼠标窗口命中穿透检查；相机没有启动。
- 真实红外设备连续两次释放并重连成功，每次重新达到 30 帧有效数据；手动暂停后注入解锁不会重新采集。测试前后功能设置和注意力校准没有改变。
- 上述恢复检查注入会话事件，不触发 Windows 锁屏，也不保存红外画面。真实 Windows Hello 登录后的相机竞争仍待人工确认。
- 0.1.1 发布目录的 Ui／Recovery／Hardware 检查通过；红外复测为 640×360 L8、12 秒 59 帧、约 4.9 fps。最终设置文件与更新前完全一致。
